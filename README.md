## Projetos em destaque

### CareConnect

Projeto colaborativo voltado a uma solução na área da saúde, com foco em
estruturação de backend e serviços de API.

-   **Tecnologias:** Python, FastAPI, Pydantic, Uvicorn, Pytest e HTTPX.
-   **Repositório:**
    [github.com/adlerjose/careconnect](https://github.com/adlerjose/careconnect)

### AI Academy

Plataforma educacional com foco em Inteligência Artificial e Engenharia
de Software, desenvolvida com tecnologias web e integração com APIs de
IA.

-   **Tecnologias:** HTML, CSS, JavaScript, Node.js, Express, Google
    Gemini API e OpenAI API.
-   **Repositório:**
    [github.com/adlerjose/ai-academy](https://github.com/adlerjose/ai-academy)

### Rede Viva --- Ernegy City

Projeto colaborativo com aplicação de tecnologias web e recursos de
visualização e interação em 3D. Participei diretamente do
desenvolvimento do projeto.

-   **Tecnologias do projeto:** React, TypeScript, Vite, Three.js, React
    Three Fiber e Zustand.
-   **Repositório:**
    [github.com/pedrohxs/ernegy-city](https://github.com/pedrohxs/ernegy-city)

### BlockBuster PIT

Sistema de gerenciamento para uma locadora, com operações de cadastro e
controle de filmes, clientes, aluguéis e vendas.

-   **Tecnologias da implementação:** Python e JSON.
-   **Recursos:** operações CRUD, organização modular e persistência de
    dados em arquivos JSON.
-   **Observação:** a interface em Streamlit foi adaptada com auxílio de
    IA e não é apresentada aqui como uma implementação técnica própria.
-   **Repositório:**
    [github.com/eniojones/BlockBuster-PIT](https://github.com/eniojones/BlockBuster-PIT)
